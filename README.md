# LLM Response Evaluator 🤖

## Overview
A lightweight Python evaluation pipeline designed to validate and benchmark outputs generated by Large Language Models (LLMs). This tool automates the process of checking AI responses for structural formatting, coding task compliance, and safety alignment (Red-Teaming).

## Features
- **Safety & Alignment Checking:** Detects standard refusal patterns to ensure the model aligns with safety guidelines.
- **Code Validation (Repo Validation):** Verifies that coding prompts generate properly formatted markdown code blocks (` ``` `) and contain expected syntax.
- **Automated Pipeline:** Processes JSON-like datasets containing prompts and responses to output an evaluation status for each test case.

## Tools & Concepts
Python, Regular Expressions (Regex), LLM Benchmarking, RLHF concepts, Red-Teaming.
